Method 1: Direct Bot Message SIMPLE

Uses sendData() - Perfect for keyboard button web apps. Sends data directly to bot and closes the app.

📝 Limitations:
  • Maximum 4096 bytes
  • One-time send only
  • App closes immediately
  • No server required
Method 2: Server Communication ADVANCED

Uses initData - For inline keyboard/menu button apps. Sends data to your server with verified authentication.

⚠️ Server Required:
  • Needs backend to receive data
  • Must validate initData signature
  • App stays open after sending
  • Supports multiple requests
🔐 Security: The initData includes a cryptographic hash that your server must verify to ensure the request is authentic and hasn't been tampered with.

View the authentication data Telegram provides to your Mini App

💡 Tip: The initData string should be sent to your server in the Authorization header for validation. Never trust data without verifying the hash!
📚 Bot Setup Instructions

For Method 1 (Keyboard Button):

# Python Bot Code from telegram import Update, KeyboardButton, ReplyKeyboardMarkup, WebAppInfo from telegram.ext import Application, CommandHandler, MessageHandler, filters async def start(update: Update, context): keyboard = [[ KeyboardButton( text="Open App", web_app=WebAppInfo(url="YOUR_APP_URL") ) ]] reply_markup = ReplyKeyboardMarkup(keyboard, resize_keyboard=True) await update.message.reply_text("Click to open:", reply_markup=reply_markup) async def handle_web_app_data(update: Update, context): data = update.message.web_app_data.data await update.message.reply_text(f"Received: {data}") app = Application.builder().token("BOT_TOKEN").build() app.add_handler(CommandHandler("start", start)) app.add_handler(MessageHandler(filters.StatusUpdate.WEB_APP_DATA, handle_web_app_data)) app.run_polling()

For Method 2 (Inline Keyboard):

# Python Bot Code from telegram import Update, InlineKeyboardButton, InlineKeyboardMarkup, WebAppInfo from telegram.ext import Application, CommandHandler async def start(update: Update, context): keyboard = [[ InlineKeyboardButton( text="Open App", web_app=WebAppInfo(url="YOUR_APP_URL") ) ]] reply_markup = InlineKeyboardMarkup(keyboard) await update.message.reply_text("Open app:", reply_markup=reply_markup)
